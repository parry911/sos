Set up the widget (once)
  1. Install Scriptable from the App Store (free).
  2. Open parry911.github.io/sos/scriptable/ in Safari, copy SOS Widget, and in Scriptable tap + and paste it. Name the script exactly SOS Widget.
  3. Do the same with SOS Sync, named exactly SOS Sync.
  4. Come back here and tap Sync widget now. Scriptable opens for a second and saves your streak.
  5. Long-press your Lock Screen → Customise → Lock Screen → tap the widget area → Scriptable. Tap the new widget and choose script SOS Widget.
Night alert (once)
  1. Open Shortcuts → Automation → + → Time of Day.
  2. Set 9:00 PM, Daily, and choose Run Immediately.
  3. Add the action Show Notification with: Danger window opens. Dinner done? If a craving hits, open SOS first.
  4. Optional: make a second one at 11:30 PM with This is when you order. Not tonight.
